Browser Limitation

Web browsers (Chrome, Edge, etc.) have strict security sandboxes and can only act as a Bluetooth Client (Sender). They cannot act as a Bluetooth Server (Receiver) to accept connections from other phones.

To transfer files between two browsers outside of WiFi (e.g. 4G/5G), please use the P2P Mode which is designed exactly for this!
